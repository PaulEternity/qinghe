连接你的模型服务

在工程目录将 .env.example 复制为 .env，填写下面三项，然后重启服务。

MODEL_BASE_URL=服务商的 API 根地址
MODEL_API_KEY=你的 API Key
MODEL_NAME=模型名称

接口需兼容 /chat/completions；手相功能需要支持图片输入的模型。密钥只由本机服务读取，不存入浏览器。

测算资料会发送给你配置的模型服务；札记存于本机 MySQL，可在“我的札记”导出或删除；原始照片和模型密钥不写入札记。没有会员、积分或支付，但服务商可能按使用量收费。
